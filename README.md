# EduOne
EduOne is a comprehensive AI-integrated educational technology platform designed to revolutionize the learning experience for students and educators through intelligent automation and personalized assistance.

✨ Key Features
📚 AI-Powered Document Q&A System

RAG (Retrieval-Augmented Generation) architecture for intelligent PDF processing

Subject-based document storage with vector database integration

Context-aware question answering using ChromaDB and Gemini API

📝 Smart Note Organization

AI-powered tagging and categorization system

Intelligent search functionality across all notes

Seamless organization with automated content analysis

📅 Academic Planner with AI Scheduling

Dashboard with comprehensive task management

AI-powered task prioritization and scheduling

Progress tracking and deadline management

Smart workload distribution

👥 Collaborative Learning Platform

Interactive forums for student discussions

Teacher-student communication tools

Shared resource management

🛠️ Technology Stack
Frontend: React, Tailwind CSS
Backend: Node.js, Express
Database: MongoDB, Qdrant (Vector Database)
AI Integration: Google Gemini API
Development: Free-tier AI services and APIs
